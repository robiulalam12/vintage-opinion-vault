# Policy Violation

1. Unzip the download.
2. Open `chrome://extensions` in Chrome, Edge, Brave, Arc, or Opera.
3. Enable Developer mode.
4. Click Load unpacked and select this folder.
5. Open Settings and add the dashboard URL, the same API key used by the DMCA extension, your country, full legal name, and 2Captcha key.
6. Open the popup, choose a prepared Policy violation order, and click Start reporting.

The extension processes exactly one written violation report per Google submission. It records completion only after Google's confirmation. Pause or Stop never marks a report submitted.
